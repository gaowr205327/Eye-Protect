# 护眼助手 — 可执行构建 Prompt

> 用法：把下面的 **"主 Prompt"** 整段复制给任意 AI（Claude、ChatGPT、DeepSeek 等）即可让它按需求从零构建本应用；
> 或自己按 **"人肉执行步骤"** 一节逐步操作。本文档自包含，不依赖需求文档即可执行。

---

## 主 Prompt（复制这一整段）

```text
请帮我开发一个 Windows 桌面小工具"护眼助手"，要求如下：

【运行环境】Windows 10/11，完全离线运行，不联网，最终打包成单个 .exe 文件。

【核心功能】
1. 每隔用户设定的间隔时间（分钟），在屏幕正中央弹出一个置顶提醒窗口，
   提示"该休息眼睛了"（落点按当前屏幕尺寸实时计算，自适应分辨率/DPI）。
2. 设置界面可自定义：提醒间隔（1~180 分钟）、提醒提示词（多行文案）、
   弹窗停留秒数、提示词展示方式（顺序循环/随机）、休息弹窗按钮文字
   （默认"知道了，继续干活"）。
3. 弹窗自动淡入淡出，点击按钮立即关闭；不抢键盘焦点。
4. 下班提醒：可设置每日下班时间（时:分）与下班提示词，到点在屏幕正中央
   弹出"下班时间到"弹窗；每天只提醒一次，次日同一时刻再触发；可整体开关；
   与休息提醒互相独立，同时到点时下班提醒优先。
5. 设置自动保存到 %APPDATA%\EyeReminder\config.json，重启后生效。
6. 系统托盘常驻 👍 图标：关闭设置窗口不退出，提醒继续；右键菜单含
   "打开设置 / 立即提醒 / 退出"。
7. 可选勾选"开机自动启动"（写 HKCU 注册表 Run 键，无需管理员权限）。
8. 单实例运行（重复双击只打开已有窗口）。
9. 设置界面提供"预览弹窗"和"开始/暂停"按钮。
10. 弹窗位置固定：休息/下班弹窗统一出现在屏幕正中央（无需任何位置设置），
    落点按当前屏幕尺寸实时计算，自适应不同分辨率/DPI。
11. 皮肤系统：内置 5 套预设皮肤（经典蓝默认/暗夜黑/清新绿/少女粉/暖阳橙），
    设置界面顶部一键切换、即时生效并自动保存；皮肤同时覆盖主界面
    （底色/卡片/按钮/输入框/文字）与提醒弹窗（色带/渐变/文字/按钮）。

【弹窗样式】
- 配色：白色底（垂直微渐变 #ffffff → #eef3ff）+ 胖次蓝（#3B6BFF）点缀
  （顶部 8px 圆角色带、按钮），标题与正文为黑色，底部小字灰色。
- 无任何徽章/图标（v1.2 起去除眼睛图标），标题居中；
  休息弹窗标题"该休息啦"、下班弹窗标题"下班时间到"。
- 休息弹窗按钮文字可自定义（设置界面输入框传入）；下班弹窗按钮固定。
- 顶部色带必须严格贴合卡片圆角轮廓绘制（按行计算圆角收缩），
  禁止全宽矩形覆盖，否则顶角会出现缺色/溢出缺陷。
- 无边框、置顶、屏幕正中央定位、从上方滑入+淡入淡出动画。

【技术约束】
- 语言：Python 3.13，GUI 用 tkinter（禁止使用需要联网下载的运行时）
- 托盘：pystray + Pillow；图标 = 胖次蓝圆底 + 👍（用 Segoe UI Emoji 字体
  C:\Windows\Fonts\seguiemj.ttf 渲染，Pillow 的 embedded_color=True；
  渲染失败必须内置手绘兜底图形），不允许运行时下载
- 打包：PyInstaller --onefile --windowed，图标打包进 exe
- 代码组织：main.py（入口+单实例）/ app.py（主控制器）/ config.py（配置）/
  scheduler.py（定时，含下班调度）/ settings_window.py（设置窗口）/
  popup.py（弹窗，休息/下班两种样式）/ tray.py（托盘）/ icons.py（图标绘制），
  放在 src/ 目录
- 所有界面文案用简体中文；应用名"护眼助手"
- 线程模型：定时用后台线程 + tkinter 主线程通过 queue/after 回传弹窗信号，
  严禁在子线程直接操作 tkinter 组件

【验收标准】开发完必须逐条自测并报告：
1. 运行不报错，设置窗口正常显示（标题"护眼助手"，图标 👍）
2. 设 1 分钟间隔能准时弹窗，弹窗在屏幕正中央且置顶
3. 弹窗为白底+胖次蓝配色、黑色文字，顶部色带与圆角贴合无缺色
4. 设下班时间（当前时刻的 1 分钟后）→ 到点弹"下班时间到"弹窗，
   文案为自定义下班提示词
5. 修改提示词后弹窗显示新文案；重启程序设置保持
6. 托盘退出后进程完全结束
7. 打包出的 exe 双击可运行

请按上述要求先给出你的实现计划，然后逐文件写代码，
最后给出 PyInstaller 打包命令和测试步骤。
```

## 人肉执行步骤（不借助 AI 时的手工流程）

### 第 1 步：准备环境（只需一次）

```bash
# 确认 Python 已安装（3.10+，推荐 3.13）
python --version

# 安装依赖
pip install pyinstaller pystray pillow
```

### 第 2 步：编写代码

按以下模块顺序编写到 `src/` 目录：

| 文件 | 职责 | 要点 |
|------|------|------|
| `config.py` | 配置读写 | 默认值：间隔45分钟、文案列表、停留10秒、随机/顺序；JSON 存 `%APPDATA%\EyeReminder\config.json`；读取失败回退默认 |
| `scheduler.py` | 定时调度 | 后台线程，间隔到点向队列投递"弹窗"事件；支持开始/暂停/重置；用 `threading.Event` 实现可取消的等待 |
| `popup.py` | 提醒弹窗 | `tk.Toplevel` 无边框、`-topmost`、`-alpha` 动画、屏幕正中央定位（(屏宽-弹窗宽)/2、(屏高-弹窗高)/2 实时计算，自适应分辨率）、从上方滑入；配色随皮肤（theme_name 参数）；"知道了"按钮 + 自动超时关闭；绝不调用 `focus_force` |
| `theme.py` | 皮肤系统 | SKINS 字典：每套皮肤含 name（中文名）+ window/popup 两组配色；`get(name)` 非法回退默认；新增皮肤只需加一份字典 |
| `settings_window.py` | 设置主窗口 | 间隔输入框+快捷按钮、多行文案 Text、随机/顺序 Radio、停留秒数 Spinbox、自启 Checkbox、开始/暂停按钮、预览按钮、状态栏显示剩余时间、皮肤切换按钮行；所有颜色取自当前皮肤（输入控件用 tk 组件直接着色，不用 ttk——vista 主题忽略 fieldbackground） |
| `tray.py` | 托盘 | pystray 图标+菜单（打开设置/立即提醒/退出）；图标用 Pillow 程序绘制（蓝色圆底+眼睛），不依赖图片文件 |
| `app.py` | 主控制器 | 串联以上组件；子线程通过 `queue.Queue` → 主线程 `root.after()` 轮询；窗口关闭事件=隐藏而非退出 |
| `main.py` | 入口 | 单实例检测（socket 绑定 127.0.0.1:42685，失败即退出或通知已有实例）；启动托盘与主窗口 |

关键实现要点（照做即可不出错）：
- **线程安全**：弹窗必须由主线程创建，子线程只往 `queue` 里 `put("show_popup")`，主线程用 `root.after(100, poll_queue)` 轮询。
- **退出**：托盘"退出"→ `os._exit(0)` 兜底（保证后台线程一起结束）。
- **打包路径**：程序内部统一用 `%APPDATA%` 存配置，绝不写 exe 所在目录。
- **开机自启**：`winreg` 写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值 = `"<exe路径>"`，用引号包裹；句柄用 try/finally 关闭。
- **单实例握手**：监听端口收到连接后必须完成应用层握手（收到请求字节 `b"H"` 回复 `b"E"`）再投递"打开设置"事件；仅 connect 成功不可信（其他程序 listen 后 TCP 也能握手）。绑定失败时：握手探测真实实例 → 退出；否则降级到备选端口运行。
- **监听线程健壮性**：accept 失败才退出线程；单个连接的异常（超时/空连接/恶意连接）必须隔离，不能 break 掉监听循环。
- **事件轮询隔离**：每个事件的处理必须单独 try/except，单事件异常不能中断 `poll_queue` 循环（否则所有后续弹窗停摆）。
- **配置安全**：bool 字段严格解析（字符串 "false" 不得变 True）；配置文件限制大小（>1MB 视为损坏）；保存用临时文件 + os.replace 原子写。
- **弹窗文本清洗**：过滤 C0 控制字符、折叠行内空白、保留换行、超长截断。
- **弹窗居中**：落点 = ((winfo_screenwidth - 弹窗宽) / 2, (winfo_screenheight - 弹窗高) / 2)，
  每次弹出实时计算 → 自适应分辨率/DPI；滑入起点取屏幕上方（y = -弹窗高）。
- **皮肤系统**：所有界面颜色禁止硬编码，统一从 theme.SKINS[config.theme] 读取；
  config.theme 校验非法值回退默认；换肤时重建设置窗口界面（配置已实时保存不丢数据）；
  弹窗通过 theme_name 参数取色。
- **下班调度**：调度线程每次循环计算"下一次休息时刻"与"下一次下班时刻"（今天 HH:MM，已过则算明天），取先到者等待；到点投递对应事件；下班触发后重算为明天。
- **👍 图标**：`ImageFont.truetype("C:/Windows/Fonts/seguiemj.ttf", size)` + `draw.text(..., embedded_color=True)`；外层 `try/except` 兜底手绘图形。

### 第 3 步：冒烟测试（开发态）

```bash
cd src
python main.py            # 启动应无报错；设 1 分钟间隔验证弹窗；Ctrl+C 退出
```

### 第 4 步：生成应用图标

用 Pillow 脚本生成 `assets/icon.ico`：胖次蓝（#3B6BFF）圆底 + 👍（用 Segoe UI Emoji 字体渲染，`embedded_color=True`；失败则手绘兜底）。

### 第 5 步：打包

```bash
# 一键打包（build.bat 内容；注意 --icon 必须用绝对路径，PyInstaller 6 会把相对路径解析到 workpath 下导致找不到文件）
pyinstaller -F -w -n 护眼助手 ^
  --icon "%~dp0assets\icon.ico" ^
  --hidden-import pystray._win32 ^
  --collect-all pystray ^
  --collect-all PIL ^
  src/main.py
# 产物在 dist/护眼助手.exe
```

参数说明：
- `-F` 单文件；`-w` 无控制台窗口；`-n` 输出名
- `--hidden-import pystray._win32`：pystray 的 Windows 后端需显式声明，否则托盘功能失效
- `--collect-all pystray / PIL`：防止 PyInstaller 漏掉子模块

### 第 6 步：验证 exe

1. 双击 `dist/护眼助手.exe` → 窗口出现（标题"护眼助手"，图标 👍）
2. 设间隔 1 分钟 → 弹窗出现在屏幕正中央、可点击关闭
3. 设下班时间 = 当前时刻的 1 分钟后 → 到点弹"下班时间到"弹窗，文案为自定义下班提示词
4. 托盘右键退出 → 任务管理器确认进程消失
5. 删除 `%APPDATA%\EyeReminder` 后重开 → 恢复默认配置
6. 断网状态重复上述 1~4 → 全部正常

### 第 7 步（可选）：分发

- 直接把 exe 发给同事即可用（绿色单文件）
- 若提示 SmartScreen，点击"仍要运行"即可；正式分发可购买代码签名证书

## 常见问题速查

| 问题 | 解决 |
|------|------|
| 托盘图标不显示 | 确认加了 `--hidden-import pystray._win32` |
| 弹窗不置顶 | 确认在 `withdraw()` 之后再 `attributes("-topmost", True)` |
| 打包后启动报 no module | 用 `--collect-all` 收集对应包 |
| 杀毒误报 | 换 `-F` 为普通目录模式（去掉 `-F`）重新打包 |
| 单实例失效（能开多个窗口） | socket 绑定端口时**禁止设置 SO_REUSEADDR**——Windows 上它会允许重复绑定 |
| 自启后不弹提醒 | 检查注册表 Run 键值是否带引号、exe 路径是否移动过 |
