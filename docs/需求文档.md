## 1. 项目概述

一款运行在 **Windows 10/11** 上的桌面小工具（单文件 .exe），**完全离线运行、不联网**。
核心功能：每隔用户设定的时间，**在屏幕正中央弹出提醒窗口**（自适应不同分辨率），提示使用者休息眼睛；
并可设置**每日 4 次上下班打卡提醒**（上班 / 午休 / 午休结束 / 下班），到点弹窗提示打卡。
用户可自定义**提醒间隔、提醒文案、各条打卡的时间与提示词、弹窗按钮文案**。

- 应用名称：**护眼助手**（exe 文件名：护眼助手.exe）
- 应用图标：**像素眼睛**（草地绿圆底 + 木质描边；v1.7 起，托盘/任务栏/窗口标题栏/exe 统一使用）
- 界面风格：**星露谷像素风**（v1.7 起，全部组件程序化 2D 像素绘制）+ 开源像素字体
- 目标用户：长时间面对电脑的办公人群
- 使用方式：双击 .exe 即可运行，无需安装（绿色软件）
- 运行环境：Windows 10 / 11（64 位为主，兼容 32 位）

## 2. 功能需求

### 2.1 核心功能（必须实现）

| 编号 | 功能 | 说明 |
|------|------|------|
| F1 | 定时提醒 | 按设定的间隔时间（分钟）循环弹出提醒，直到用户暂停/退出 |
| F2 | 弹窗展示 | 提醒窗口出现在屏幕正中央（按当前屏幕尺寸实时计算落点，自适应分辨率/DPI），置顶显示，不影响正在使用的程序 |
| F3 | 间隔可设置 | 用户在设置界面输入提醒间隔（分钟），建议 1~180 分钟 |
| F4 | 提示词可设置 | 用户可自定义提醒文案（支持多行、多段），随机或按顺序展示 |
| F5 | 弹窗自动消失 | 弹窗停留数秒后自动淡出，也可点击按钮立即关闭 |
| F5b | 按钮文字可自定义（v1.2，v1.7 扩展） | 休息弹窗按钮文字（默认"知道了，继续干活"）可在设置页自定义；**打卡弹窗另有独立的一项**（默认"已打卡，继续"），二者互不影响 |
| F6 | 配置保存 | 设置自动保存，下次启动沿用（配置文件存于用户目录，不污染 exe 目录） |

## 3. 交互设计

### 3.1 设置主窗口（v1.7 改为三标签页）

```
┌──────────────────────────────────────────────┐
│  👁 护眼助手                    [—] [✕]      │  ← 像素木牌招牌（木纹+铆钉+叶片）
├──────────────────────────────────────────────┤
│  🌱 定时休息 · 每日打卡                       │
│  (👁 主功能) (☑ 打卡提醒) (⚙ 设置)            │  ← 三标签页，各带 16px 像素图标
│  ～～～～ 装饰分隔条：嫩芽·草簇·小花 ～～～～    │
├──────────────────────────────────────────────┤
│  ┌─ ⏱ 提醒间隔 ─────────────────────────┐   │
│  │   [ 45 ] 分钟              (1 ~ 180)  │   │
│  │   快捷设置：(20分)(25分)(45分)(60分)  │   │
│  └───────────────────────────────────────┘   │
│  ┌─ ▤ 提醒文案（每行一条，轮流展示）─────┐   │
│  │   ┌─────────────────────────────────┐ │   │
│  │   │ 眼睛累了，去看看远处 20 秒吧～  │ │   │
│  │   │ 记得眨眼，记得喝水              │ │   │
│  │   └─────────────────────────────────┘ │   │
│  │   (●) 顺序轮换    ( ) 随机            │   │
│  └───────────────────────────────────────┘   │
│  [ 预览弹窗 ]  休息 45分00秒 · 下班打卡 4:10:02 │
│                              [ 开始提醒 ]     │
├──────────────────────────────────────────────┤
│  🌿 底部草地装饰带（抖动渐变+泥土+草丛+小花） │
└──────────────────────────────────────────────┘
```

- 窗口约 470 宽，高度随当前标签页自适应（主功能 ≈640 / 打卡提醒 ≈675 / 设置 ≈677）
- **像素风绘制（v1.7）**：招牌、卡片、按钮、输入框底板、标签页、分隔条、底部装饰带
  全部由 `pixelart.py` 在低分辨率原生网格上逐像素绘制，再整数倍 NEAREST 放大 ——
  阶梯圆角、厚木框、四角铆钉、硬偏移投影（无模糊）、Bayer 抖动渐变
- **原生控件叠加方案**：`ttk.Spinbox / Entry / Checkbutton / Radiobutton` 由系统绘制、无法像素化，
  做法是外面套一层像素木框 **PNG 底板**，把原生控件叠在底板之上（见 `_field_native`）；
  控件底色/文字色取自当前配色，视觉上与像素框融为一体
- **像素字体（v1.7）**：`fonts.py` 以 `AddFontResourceExW(FR_PRIVATE)` 只对本进程注册
  Fusion Pixel 12px，并同步替换 Tk 8 个内置命名字体（`TkDefaultFont` 等）与 `*Font`，
  因此原生控件的数字/文字也跟随成像素字；**字号必须是 12 的整数倍**（12/24），
  非整数倍（13/16）会因栅格不对齐而发虚
- 所有修改即时生效并自动保存；顶部不再有皮肤切换行（v1.7 单皮肤）

### 3.2 提醒弹窗（v1.7 改为像素木牌）

```
        （屏幕正中央）     休息提醒                      打卡提醒
┌──────────────────────────────┐  ┌──────────────────────────────┐
│🌿 ▓▓▓ 木纹木框 + 铆钉 ▓▓▓  ⬤│  │🌿 ▓▓▓ 木纹木框 + 铆钉 ▓▓▓  ⬤│
│          👁 该休息啦          │  │          ☑ 午休结束           │
│                              │  │                              │
│   眼睛累了，看看远处 20 秒吧～ │  │  午休结束，记得打卡回来上班。 │
│   记得眨眼，记得喝水。        │  │                              │
│       [ 知道了，继续干活 ]    │  │      [ 已打卡，继续 ]         │
│ 🌱下次提醒 45 分钟后(5s自动关闭)│ │ 🌱每天 13:30 打卡(5s 自动关闭)│
│                          🌸  │  │                          🌸  │
└──────────────────────────────┘  └──────────────────────────────┘
```

- 尺寸约 340×212（打卡弹窗因文案行数不同略有差异），无边框、置顶、**屏幕正中央**
  （按当前屏幕尺寸实时计算落点，自适应分辨率/DPI）
- **像素木牌样式（v1.7）**：木质外框（钉在羊皮纸上）+ 羊皮纸底（Bayer 抖动底纹，
  刻意减淡以保证正文可读）+ 左上叶片 / 右下小花 / 左下草簇装饰 + 硬偏移投影
- **圆角真正镂空**：窗口用 `overrideredirect(True)` + `attributes("-transparentcolor", 键色)`
  把四个角挖掉，配合带 alpha 的 PNG 木框底板，角外完全透明
- **阶梯帧动画（v1.7）**：滑入 8 帧 @40ms（≈12fps），透明度只取 4 档 ——
  像素风必须"跳帧"，线性插值会立刻破坏像素感；停留 N 秒后同样分帧淡出
- **文字描边**：中文像素字压在木面/羊皮纸上时用环形偏移描边增强可读性，
  描边色**跟底色明暗走**（深底用墨色、浅底用奶油色）
- 非模态，不抢焦点、不打断输入：`attributes("-topmost")` 保证置顶，绝不调用 `focus_force()`
- 休息提醒：标题"该休息啦"、按钮文字**可自定义**（默认"知道了，继续干活"，设置页"弹窗按钮文案"卡片可改）、底部显示下次提醒时间
- 打卡提醒：标题为打卡名称（"上班打卡"/"午休打卡"/"午休结束"/"下班打卡"）、
  按钮文字可自定义（默认"已打卡，继续"）、底部显示"每天 HH:MM 打卡（Ns 自动关闭）"

### 3.3 托盘

- 图标：**像素眼睛**（草地绿圆底 + 木质描边 + 眼睛，16×16 原生像素绘制后整数倍放大；
  v1.7 由 👍 改为像素眼睛，托盘/任务栏/窗口/标题栏/exe 统一使用）
- 图标**纯代码生成**，无外部图片依赖；exe 用的 `.ico` 由 `scripts/make_icon.py`
  调用同一套绘制代码生成（多尺寸 16/32/48/64/128/256）
- 悬停提示：护眼助手
- 左键单击：显示/隐藏设置窗口
- 右键菜单：打开设置 / 立即提醒 / 退出

## 4. 技术方案

| 项 | 选择 | 理由 |
|----|------|------|
| 语言 | Python 3.13+（当前环境 3.14）| 已装好，生态成熟 |
| GUI | tkinter（内置） | 零额外依赖、打包体积小、离线可用 |
| 定时 | threading.Timer / 主线程 after() | 定时提醒，精度要求低 |
| 托盘 | pystray + Pillow | 轻量、稳定、支持 Windows |
| **界面绘制（v1.7）** | **Pillow 逐像素绘制 + `Image.NEAREST` 整数倍放大** | 真像素画：阶梯圆角/厚木框/铆钉/木纹/Bayer 抖动渐变/16px 手绘图标。**零外部图片素材**，全部程序化生成 |
| **字体（v1.7）** | **Fusion Pixel 12px（OFL 1.1）** | 开源可商用的中文像素字体；`AddFontResourceExW(FR_PRIVATE)` 只对本进程注册，不写注册表；字号取 12 的整数倍保证栅格对齐 |
| 图标 | 像素眼睛（`pixelart.app_icon`）+ Pillow 生成 .ico | 纯代码生成，无外部图片依赖 |
| 配置 | JSON 文件 → `%APPDATA%\EyeReminder\config.json` | 不污染 exe 目录，兼容开机自启 |
| 配色 | theme.py：SKINS 字典（v1.7 仅经典蓝一套，39 个色键）| 绘制层统一取色；config.theme 存皮肤键，非法值回退默认 |
| 打包 | PyInstaller --onefile/--onedir --windowed + `--add-data` 字体 | 单文件绿色 exe；字体是唯一需要随包分发的文件资源 |
| 单实例 | socket 绑定固定端口 + 应用层握手（**禁用 SO_REUSEADDR**）| Windows 上 SO_REUSEADDR 允许重复绑定会破坏单实例；仅 TCP 连接成功无法区分真实实例与其他占用者，需握手确认 |
| 开机自启 | winreg 写 HKCU\...\Run | 不需要管理员权限 |

### 4.2 安全设计（v1.3 审查加固）

| 面 | 措施 |
|----|------|
| 单实例 DoS | 端口绑定失败时先握手探测：真实实例则退出；其他程序占用则**降级用备选端口（42686）继续运行**；双端口均被占才提示退出 |
| 单实例监听线程 | 应用层握手（请求 H / 响应 E）；恶意空连接/超时被隔离，不杀死监听线程 |
| 配置输入 | bool 严格解析（仅 true/false/0/1/yes/no/on/off，无法识别回退默认）；数值 clamp 校验；文案上限 100 条 × 200 字符 |
| 配置完整性 | 文件大小上限 1MB（超限视为损坏回退默认）；**原子写**（临时文件 + fsync + replace）；损坏自动备份 .bak |
| 弹窗文本 | 过滤 C0 控制字符、折叠行内空白、保留换行、超长截断（防 UI 异常与资源耗尽） |
| 事件轮询 | 单事件异常隔离，任何异常不中断轮询（防弹窗停摆） |
| 注册表 | HKCU Run 键 try/finally 确保句柄关闭；仅写本应用专属键名 |
| 网络面 | 全程序零外部网络调用；仅监听 127.0.0.1 回环端口 |
| 权限 | 全程无需管理员权限（仅 HKCU + %APPDATA%） |

## 6. 风险与对策

| 风险 | 对策 |
|------|------|
| 杀毒软件误报 | 使用 `--onefile --windowed` 常规打包；可附 VirusTotal 说明 |
| PyInstaller 兼容 pystray | 打包时加 `--hidden-import pystray._win32` |
| 弹窗抢焦点打扰用户 | 弹窗永不调用 focus_force，仅置顶展示 |
| 用户改了系统 DPI | 弹窗位置用 `winfo_screenwidth/height` 实时计算 |
| 配置损坏 | 读取失败时回退默认值并备份坏文件 |
| 像素图标渲染失败 | 图标由 `pixelart` 程序化绘制，不依赖字体或图片，任何环境下不缺失 |
| **像素字体加载失败 / 文件缺失（v1.7）** | `fonts.py` 加载前用 PIL 在两档字号试渲染校验，不合格或找不到文件即**回落系统字体**，绝不出现空白界面；`build.bat` 打包时也会检查字体并在缺失时给出警告 |
| **像素字体被误用非栅格字号（v1.7）** | 字号统一由 `fonts.py` 的 `SIZE_*` 常量集中定义（12/24），禁止散落硬编码；文档注明必须取 12 的整数倍 |
| 单实例端口被其他程序占用 | 握手探测区分真实实例 → 备选端口降级启动（见 §4.2） |
| 杀毒软件误报 | PyInstaller 常规打包；Defender 实测无威胁告警 |
